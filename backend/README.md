# Tripleten web_project_around_express


Projeto 15 – API de Usuários e Cartões

Descrição do projeto e sua funcionalidade

Este projeto é uma API simples desenvolvida em Node.js com Express. A aplicação fornece dados de usuários e cartões a partir de arquivos JSON locais, respondendo a requisições HTTP e retornando os dados em formato JSON. Também há tratamento de erros para rotas inexistentes e para buscas de usuários que não existem.

Tecnologias e técnicas utilizadas

Node.js

Express.js

JavaScript

Módulo fs para leitura de arquivos

Módulo path para resolução de caminhos

ESLint com configuração airbnb-base
