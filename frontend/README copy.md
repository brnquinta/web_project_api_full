# Around — Primeiro Projeto em React

Around é um projeto simples feito em React focado apenas em interface. Ele permite editar o perfil (nome e profissão), adicionar novos cards com imagem e visualizar uma imagem ampliada ao clicar em um card. O projeto foi desenvolvido para praticar estados, renderização condicional, componentes reutilizáveis, props e manipulação básica de UI.

Tecnologias utilizadas: React (useState, componentes funcionais), JavaScript ES6+, HTML5 e CSS3.

Funcionalidades:
- Editar perfil
- Adicionar novo card
- Visualizar imagem em popup
- Popup genérico reutilizável
- Renderização dinâmica de cards com .map

Instalação:
npm install
npm run dev

Estrutura resumida: componentes Popup, EditProfilePopup, NewCard, ImagePopup, Card e o componente Main que controla estados e lógica dos popups.

Objetivo: aprender os fundamentos de React, incluindo controle de estado, renderização condicional, organização de componentes e criação de interfaces dinâmicas.
